# PALETTE LOG

自分のイラスト作品を保管して、時系列・色・黒猫（お気に入り）から眺め直すための個人用アーカイブ。
作品の優劣は決めない。自分の絵の傾向と変化を観察するための道具。

アプリ名は `js/config.js` の `APP_NAME` を書き換えると変わる。

## できること（MVP）

1. **一括アップロード**：「＋ 追加」で複数選択、または画面のどこにでもドラッグ＆ドロップ。JPEG / PNG / WebP など
2. **制作日の自動取得**：EXIF → メタデータ（XMP・PNGのCreation Time）→ ファイル日時 → 不明 の順に探す
   - 取得元（EXIF／メタデータ／ファイル日時／手動／不明）を作品ごとに記録して表示
   - ファイル日時が「取り込んだ瞬間」とほぼ同じなら信用せず「不明」にする（スマホで選ぶとこうなりやすい）
   - 詳細画面で手動変更できる。手動の日付は自動の日付より優先。「自動に戻す」「不明にする」もできる
3. **タイムライン**：年・月ごとに区切って表示。新しい順／古い順を切り替え。日付不明は最後にまとめる
4. **色の抽出**：代表色・主要5色・平均明度・平均彩度・暖色／寒色／ニュートラル・色系
5. **色フィルター**：暖色／寒色／ニュートラル、低彩度／高彩度、暗い／明るい、赤・黄・緑・青・紫系
   - 同じ列の中では1つまで選べる。列が違うものは「かつ」で組み合わさる
6. **黒猫マーク**：詳細画面でワンタップ。付けると作品の隅に黒猫が静かに座る。「黒猫」フィルターあり
7. **ギャラリー**：トリミングしない。縦横比のまま、1行ごとに高さを揃えて並べる

詳細画面では ←→ キーやスワイプで前後の作品へ、F キーで黒猫、Esc で閉じる。

## 大事な注意：データの置き場所

作品はすべて **このブラウザの中（IndexedDB）** に保存される。サーバーには送らない。

- 別の端末やブラウザとは共有されない
- ブラウザのサイトデータを消すと、作品も消える
- **iPhone / Mac の Safari は、ホーム画面に追加していないサイトのデータを、7日間使わないと消すことがある**
  → スマホでは必ず「ホーム画面に追加」してから使う
- 元画像は別に保管しておくこと。バックアップ機能は次の段階で作る予定

## 元画像について

取り込んだファイルは **一切加工せずそのまま保存** している（再圧縮・リサイズなし）。
ギャラリーには別に作った軽いサムネイル（長い辺640px）を使い、詳細画面でだけ元画像を読み込む。

## ファイルの役割

| ファイル | 担当 | こんなときに触る |
|---|---|---|
| `index.html` | 画面の骨組み・文言 | 見出しやボタンの文字を変えたい |
| `style.css` | 見た目（色・余白・黒猫の動き） | 色やギャラリーの行の高さを変えたい（一番上にまとめてある） |
| `js/config.js` | 設定値 | アプリ名、サムネイルの大きさ、「暗い／明るい」などの境目を変えたい |
| `js/db.js` | 保存（IndexedDB） | 保存項目を増やしたい、将来クラウド保存にしたい |
| `js/date-reader.js` | 画像から日時を探す | 日時の探し方を変えたい |
| `js/color.js` | 色の解析 | 色の抽出方法や暖色／寒色の判定を変えたい |
| `js/model.js` | 制作日の決め方・並べ方・表示名 | 日付の表示形式や並べ方を変えたい |
| `js/filters.js` | フィルターの定義 | フィルターを足したい・減らしたい |
| `js/cat.js` | 黒猫の絵 | 黒猫の形を変えたい |
| `js/importer.js` | 取り込みの流れ | 取り込み時の処理を足したい |
| `js/gallery.js` | ギャラリーの表示 | 一覧の見せ方を変えたい |
| `js/detail.js` | 作品詳細の表示と操作 | 詳細画面の項目を変えたい |
| `js/app.js` | 全体の流れ・ボタンのひも付け | 新しいボタンを足したい |

読み込み順は index.html の一番下（設定 → 保存 → 解析 → 表示 → 全体の流れ）。

## データの形

IndexedDB `palette-log` に3つの棚：

- `artworks`：作品情報（下の形）
- `originals`：元画像（キーは作品id）
- `thumbs`：サムネイル（キーは作品id）

```
Artwork {
  id, fileName, fileType, fileSize, fileKey,
  width, height, thumbWidth, thumbHeight,
  importedAt,                     // アプリに取り込んだ日時
  fileLastModified,
  autoDate, autoDateSource,       // 自動で取れた日付と取得元（exif / metadata / file / unknown）
  manualSet, manualDate,          // 手動の日付（manualSet=true が優先。manualDate=null なら手動で不明）
  favorite, favoritedAt,          // 黒猫
  color: { version, dominant, palette:[{hex, share}], brightness, saturation, temperature, hues },
  tags: []                        // 将来の雰囲気タグ用（いまは空）
}
```

## 将来の拡張のための用意

- **AIの雰囲気タグ**：`tags` に `{ name, source:'ai', status:'suggested' }` で候補を入れ、
  ユーザーが採用したら `status:'accepted'` にする想定。AIが勝手に確定しない、評価しない
- **色の解析方法を変えたとき**：`color.version` で古い結果を見分けて、取り込み直さずに再計算できる
- **クラウド保存・同期・バックアップ**：`js/db.js` を差し替える
- アイデアのメモは `IDEAS.md`

## 動かし方

- パソコン：フォルダごと Vercel などに置く。ローカルで試すなら簡易サーバーを立てて開く
  （`index.html` を直接ダブルクリックだと、ブラウザによっては保存が効かない）
- 公開：このフォルダの中身を GitHub に置いて Vercel にデプロイ（ビルド設定は不要）
